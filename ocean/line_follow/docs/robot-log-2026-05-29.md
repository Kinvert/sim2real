## Interpretation

The physical robot did not simply drive at the wheel floor. It turned correctly
when a sensor saw strong black. The slow behavior came mostly from common
`flags=0` states where the sensors saw weak/intermediate line signal below the
hard threshold. Those states should be represented regularly in the simulator's
domain randomization before changing reward logic.

Use this log to check whether simulated QTI raw values and normalized Q1000
values produce similar distributions for half-edge and weak-line cases.

The comparison command is:

```bash
.venv/bin/python ocean/line_follow/scripts/line-follow-qti-domain-report.py \
  --robot-csv ocean/line_follow/build/line-follow/lf000_20260529.csv
```
